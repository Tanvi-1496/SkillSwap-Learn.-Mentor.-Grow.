Design a complete modern, premium, responsive web application called **SkillSwap — Peer-to-Peer Student Mentorship & Skill Sharing Marketplace**.

SkillSwap is a college-focused platform where students can discover verified mentors such as senior students, faculty members, alumni, and industry professionals. Mentees can search for mentors based on skills and requirements, receive AI-powered mentor recommendations, book mentorship sessions, track bookings, provide feedback, and interact with an AI chatbot.

The design should feel like a combination of a **modern SaaS dashboard + professional mentorship marketplace + student learning platform**. The interface must be clean, modern, friendly, trustworthy, and highly usable.

---

## 1. BRANDING & VISUAL STYLE

Product name: **SkillSwap**

Tagline:
**Learn from the right person. Grow with the right guidance.**

Design style:

* Modern SaaS
* Clean and minimal
* Professional but student-friendly
* Premium UI
* Rounded cards
* Subtle shadows
* Clear hierarchy
* Spacious layouts
* Smooth micro-interactions
* Accessible contrast
* Responsive desktop and mobile layouts

Use a consistent design system throughout the website.

Suggested color direction:

* Primary: deep indigo / blue-purple
* Secondary: soft violet / blue
* Background: very light neutral
* Cards: white
* Success: green
* Warning: amber
* Error: red

Typography:

* Use a modern sans-serif such as Inter, Manrope, or Plus Jakarta Sans.
* Large bold headings
* Clear readable body text
* Strong visual hierarchy

Use professional icons and subtle illustrations where appropriate.
